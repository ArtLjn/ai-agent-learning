# 快递、收发室与公司邮寄

## 文档信息

- 文档编号：YZ-ADM-MAIL-001
- 公司：云舟科技有限公司
- 归口部门：行政服务、收发室
- 关联平台：云舟员工门户、钉钉通知
- 版本：2026.07

## 适用场景

- 员工不知道快递收件地址和收发室位置。
- 公司文件、合同、设备或礼品需要对外邮寄。
- 员工快递丢失、延迟、签收人不明或破损。
- 离职或远程办公员工需要寄回设备。

## 收件规则

- 私人快递建议寄到个人住址，公司收发室优先处理公司业务件。
- 公司业务件收件人需写清部门、姓名、手机号和楼层。
- 合同、发票、证照、设备等重要件应选择可追踪快递。
- 涉及客户资料、合同原件、设备和证照时，不得无记录转寄。

## 寄件流程

1. 在云舟员工门户搜索“公司寄件申请”。
2. 填写寄件原因、收件方、地址、物品类型、是否保价和成本中心。
3. 合同、证照、设备类物品需上传审批或归口部门确认。
4. 收发室打印面单并记录运单号。

## 服务台信息收集

- 员工号、部门、办公地点。
- 快递公司和运单号。
- 收件人或寄件人信息。
- 物品类型：文件、合同、发票、设备、礼品、私人物品。
- 当前状态截图和期望处理时间。

## 常见问题处理

| 问题 | 处理口径 |
| --- | --- |
| 快递显示签收但没收到 | 查收发室签收记录和取件通知 |
| 设备寄回 | 需同步 AssetOne 资产状态 |
| 合同原件邮寄 | 需法务或合同负责人确认 |
| 快递破损 | 保留照片和包装，联系快递公司 |

## 回复模板

您好，请提供运单号、快递公司、收件人、办公地点和物品类型。若是公司合同、发票或设备，请补充审批单号或资产编号，我们会协助收发室核查签收、存放和转寄记录。

## 升级条件

- 合同、证照、发票、设备或客户资料遗失。
- 批量快递无法签收或派送异常。
- 离职设备未寄回影响权限回收。
