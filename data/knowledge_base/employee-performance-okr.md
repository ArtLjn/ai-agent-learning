# 绩效、OKR 与目标校准

## 文档信息

- 文档编号：YZ-HR-OKR-001
- 公司：云舟科技有限公司
- 归口部门：HR 绩效组
- 关联平台：PeopleHub、钉钉通知
- 版本：2026.07

## 适用场景

- 员工不知道 OKR 在哪里填写。
- 员工目标无法提交、主管无法评分或系统权限异常。
- 员工咨询绩效周期、校准会、反馈记录和申诉入口。
- 员工对绩效结果、奖金或调薪有疑问。

## 处理边界

绩效结果、评分、奖金和调薪属于敏感事项。服务台只负责入口指引、系统故障受理和流程说明，不解释个人绩效结果，不承诺奖金或调薪，不在工单中展示绩效详情。

## 常见入口

| 事项 | 入口 |
| --- | --- |
| OKR 填写 | PeopleHub > 绩效 > 我的 OKR |
| 目标对齐 | PeopleHub > 目标地图 |
| 绩效反馈 | PeopleHub > 绩效反馈 |
| 申诉入口 | PeopleHub > 绩效申诉 |
| 周期公告 | 钉钉 HR 公告 |

## 服务台信息收集

- 员工号、绩效周期。
- 问题类型：无法填写、无法提交、主管看不到、评分不可见、申诉入口不可用。
- 系统截图，需遮挡绩效评分和敏感评价。
- 是否临近提交截止时间。

## 常见问题处理

| 问题 | 处理口径 |
| --- | --- |
| OKR 提交按钮灰色 | 检查周期是否开放、主管关系是否同步 |
| 主管看不到下属 | 核查 PeopleHub 汇报关系 |
| 评分不可见 | 确认绩效阶段和发布时间 |
| 对结果有异议 | 引导绩效申诉或 HRBP |

## 回复模板

您好，请提供员工号、绩效周期、问题截图和当前所在流程阶段。服务台可协助核查 PeopleHub 入口、权限和汇报关系；绩效结果、奖金、调薪和申诉解释需由 HR 绩效组或 HRBP 处理。

## 升级条件

- 大量员工无法提交 OKR 或主管无法评分。
- 截止日前系统异常影响绩效流程。
- 员工提出绩效结果争议、申诉或薪酬关联问题。
