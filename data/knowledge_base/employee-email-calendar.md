# 邮箱、日历与会议邀请

## 适用场景

- 员工无法登录邮箱、无法收发邮件或频繁退信。
- 日历邀请不同步，会议室预订和参会人状态异常。
- 新员工邮箱未创建，离职或转岗邮箱权限需要调整。
- 邮件附件过大、被安全策略拦截或误判为垃圾邮件。

## 常见排查

1. 确认邮箱账号是否已创建，密码和 MFA 是否正常。
2. 查看网络、客户端版本、浏览器缓存和邮箱容量。
3. 根据退信信息判断是否为收件人地址、附件大小、黑名单或安全策略问题。
4. 日历问题需核对时区、会议室资源、重复会议和同步客户端。
5. 涉及敏感附件或外发拦截时，按信息安全流程处理。

## 服务台处理标准

收集邮箱地址、报错截图、退信原文、邮件发送时间、收件人域名和附件类型。普通配置问题由服务台处理；邮件安全拦截、外部域名信誉、批量退信应转 IT 或安全团队。

推荐分类：`technical`。

## 回复模板

您好，请提供邮箱地址、发生时间、报错截图或退信原文。如果是日历问题，请补充会议主题、会议室名称、参会人和客户端类型。我们会协助核查账号、容量、同步和安全策略。

## 升级条件

- 公司域名批量退信或外部无法收到邮件。
- 高管会议、客户会议或面试会议受到影响。
- 邮件包含敏感数据并触发安全拦截。

## 云舟科技邮箱标准

- 邮箱域名：`@yunzhou.example`。
- 邮箱系统：MailBox Pro，入口在 CloudID 应用列表。
- 日历系统：与邮箱同源，会议室资源由行政维护。
- 新员工邮箱命名：优先使用拼音全拼，重名时追加数字。
- 离职员工邮箱保留和转发规则由 HR、直属主管和 IT 共同确认。

## 常见员工问题

| 员工问题 | 处理口径 |
| --- | --- |
| 新员工没有邮箱 | 核查 PeopleHub 入职状态和邮箱创建任务 |
| 邮件发不出去 | 收集退信原文、收件人、附件大小和发送时间 |
| 合作方收不到邮件 | 检查域名信誉、黑名单、SPF/DKIM/DMARC 状态 |
| 日历不提醒 | 核查客户端通知权限、时区和同步状态 |
| 会议室预订失败 | 核查会议室资源、权限、时间冲突和行政维护状态 |

## 会议室日历处理

会议室资源由行政维护，IT 负责邮箱和日历系统可用性。若员工无法预订会议室，先确认会议室名称、时间段、参会人数、是否需要投屏设备。若会议即将开始，应同时通知行政现场支持和 IT 值班。

## 回复模板扩展

您好，请提供邮箱地址、发生时间、客户端类型和错误截图。如果是发信失败，请附上退信原文；如果是会议室问题，请提供会议室名称、会议时间和是否影响客户或面试安排。我们会先核查邮箱账号、容量、日历同步和会议室资源状态。
